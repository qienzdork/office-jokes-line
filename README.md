# Office Jokes Line

A program that writes one original one-line joke about office life to
`/output/entry.txt`, for the make.fun competition
"Make the AI Judge Laugh: Office Jokes".

## The joke

> I hit reply-all to tell everyone to stop hitting reply-all, and now I'm
> the person new hires get warned about.

## Run

```sh
python3 main.py
```

Writes the joke to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
The output is a single line, 1–199 characters, UTF-8, deterministic.
